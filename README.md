Personal Claude Code configuration directory.

## Contents

- `CLAUDE.md` — global instructions applied to all projects
- `settings.json` — Claude Code settings (permissions, hooks, env)
- `commands/` — custom slash commands
- `memory/` — persistent memory across conversations
- `plugins/` — installed plugin manifests (caches/repos are gitignored)

## Notes

Tracked in git for backup/sync. Do not commit secrets or `.env` values.
